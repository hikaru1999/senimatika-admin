# Senimatika Map Editor & Admin Panel

Platform manajemen konten untuk ekosistem belajar Senimatika. Proyek ini dibangun menggunakan **React**, **Vite**, dan **Firebase** untuk mengelola peta permainan, bank soal, dan data pengguna secara real-time.

## Fitur Utama
- **Map Editor**: Pembuatan dan pengeditan level game secara visual.
- **Question Bank**: Manajemen soal kuis dengan dukungan LaTeX dan preview instan.
- **User Manager**: Pemantauan metrik pengguna dan statistik koin.
- **Document Export**: Ekspor soal ke format PDF dan Word (.docx).

## Teknologi
- React.js (Vite)
- Firebase (Firestore & Auth)
- KaTeX (Rendering Matematika)
- EasyMDE (Markdown Editor)

## Instalasi Lokal

1. Clone repositori:
   ```bash
   git clone https://github.com/username/senimatika-map-editor.git
   ```
2. Instal dependensi:
   ```bash
   npm install
   ```
3. Konfigurasi Environment:
   Salin `.env.example` menjadi `.env` dan isi dengan konfigurasi Firebase Anda sendiri.
4. Jalankan aplikasi:
   ```bash
   npm run dev
   ```
